# UTF-8 Validation

This project contains a Python function that determines whether a given list of integers represents a valid UTF-8 encoding.

## Files

* `0-validate_utf8.py` - Function that validates UTF-8 encoding.
* `0-main.py` - Test file used to verify the implementation.

## Requirements

* Python 3.4.3
* Ubuntu 14.04 LTS
